# 기존 OX 문제·기록을 PC와 갤탭에서 공유하기

2026-10-24. 원문 앱과 같은 로그인 계정을 사용하되 OX 문제·기록과 통계는 별도로 보존한다. 원래 PC 문제와 기록을 지우지 않고 전체 백업을 미리본 뒤 계정 자료에 합친다.

## PC에서 기존 자료 보관

1. 지금까지 사용한 OX 주소를 기존 PC 브라우저에서 연다. 실제 학습 영역인지 확인한다. 로컬 개발 앱은 `http://127.0.0.1:5173/?mode=real`이다.
2. 진행 중 학습이 있으면 가능하면 완료하거나 종료한다. 진행 중 세션은 다른 기기의 활성 세션으로 옮기지 않는다.
3. OX `데이터·설정`에서 전체 백업 JSON을 내보내 따로 보관한다. 문제만 내보낸 파일에는 학습 기록이 없으므로 기록 이전에는 **전체 백업**이 필요하다. 원문 앱의 `police-learning-backup` 통합 백업에 OX 전체 백업이 포함돼 있다면 그 파일도 선택할 수 있다.

기존 브라우저 데이터·앱·백업을 삭제하지 않는다. localhost와 공개 웹 주소는 저장 공간이 다르므로 같은 프로그램으로 보이더라도 기록이 자동 복사되지는 않는다. 백업에는 개인 학습 자료가 있으므로 공개 GitHub에 올리지 않는다.

## PC 웹 앱에서 계정에 연결

1. [공개 웹 앱의 OX 학습실](https://ttjj1117-creator.github.io/police-ox/?view=ox&mode=real)을 연다. 원문 앱에서 OX로 이동해도 된다.
2. `OX 계정·기기 동기화`를 연다. 아직 로그인하지 않았다면 `로그인·서버 설정 열기`에서 원문 앱에 사용한 이메일로 로그인한다. 이미 공통 계정에 로그인했다면 추가 계정을 만들 필요가 없다. 로그인 메일은 앱을 사용할 브라우저에서 연다.
3. 같은 웹 주소의 로그인 전 OX 기록은 `로그인 전 OX 기록 미리보기`를 누른다. 이전 PC나 다른 주소의 자료는 `기존 OX 전체 백업`에서 파일을 선택한다.
4. 표시되는 **지문 수·완료/종료 세션 수·응답 수·내용 충돌 수**와 계정 이메일을 확인한다. 원래 ID와 시각을 유지하는 병합이다. 같은 백업의 같은 기록은 반복 생성하지 않는다.
5. `미리보기 확인하고 OX 계정에 연결`을 누른다. `지금 동기화` 후 동기화 완료와 전송 대기 0건을 확인한다. 내용 충돌이나 응답 순서 확인이 남으면 먼저 백업과 복구 파일을 내보내고 해당 기록을 비교한다.

원본 자료와 백업은 보존한다. 진행 중 기록이 있는 백업은 연결을 멈추고 먼저 기존 기기에서 완료하거나 종료하도록 안내한다. 기존 기기에서 마친 뒤 새 전체 백업을 만들어 다시 연결한다. 현재 로그인한 계정에 진행 중 OX 세션이 있어도 먼저 마쳐야 한다. 원문 객관식에 이미 연결한 문제와 기록은 OX 연결 때문에 합산되거나 대체되지 않는다.

## 갤탭에서 확인

1. 갤탭 Chrome 또는 설치한 앱에서 **같은 공개 주소**를 열고 PC와 같은 이메일로 로그인한다. 로그인 메일 링크도 갤탭의 사용할 브라우저에서 연다.
2. OX 학습실의 `OX 계정·기기 동기화`에서 `지금 동기화`를 누른다. 첫 문제은행 다운로드가 끝날 때까지 인터넷에 연결한다.
3. 지문·완료/종료 세션·응답 수와 다시 보기를 확인한다. 과거 세션을 열어 당시 문항·판단 스냅샷과 원래 응답을 확인한다. 현재 학습은 기존 현행 기준 정책을 따르며, 출제 당시 판단이나 이전 판단 버전의 기록은 보존하되 현행 정오 통계에 섞지 않는다.
4. 갤탭에서 짧은 OX 학습을 완료한 뒤 전송 대기 0건을 확인한다. PC에서도 동기화하여 그 완료 기록이 보이는지 확인하면 양방향 전송을 확인할 수 있다.

갤탭에서 이미 원문 앱을 홈 화면에 설치했다면 같은 앱 안에서 OX로 이동할 수 있다. 별도의 유료 가입은 필요하지 않다. 실제 설치 메뉴와 브라우저별 동작은 해당 기기에서 확인한다.

## 인터넷 없이 학습할 때

미리 내려받은 지문으로 학습하면 답안을 이 기기에 저장한다. 완료하거나 종료한 기록은 전송 대기에 남는다. 인터넷이 다시 연결되면 앱을 열고 동기화 완료·전송 대기 0건을 확인한다. 앱을 완전히 닫은 동안 자동 전송됐다고 가정하지 않는다.

두 기기의 진행 중 세션·현재 위치·순회 잔여 목록·균형 배정·글자 크기는 각각 유지한다. 학습을 마친 뒤 같은 문제의 교차 기기 응답 선후를 확정할 수 없으면 원본을 모두 남기고 대표 기록 확인을 요청한다. `이 기기에 저장됨`은 로컬 저장 성공이며 서버 전송 완료와는 다르다.

새 버전 알림이 보이면 진행 중 학습을 마친 뒤 업데이트를 적용한다. 화면이 예전 버전이면 열린 학습을 종료하고 앱 창을 모두 닫았다가 다시 연다. 기록 이전을 위해 브라우저 데이터를 지우지 않는다.
