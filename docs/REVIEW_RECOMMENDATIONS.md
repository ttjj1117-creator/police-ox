# 복습 단원 추천·학습 현황

작성일: 2026-10-23 (Asia/Seoul)

기존 원문 객관식 학습실 안에서 현재 풀이 기록으로 복습할 단원을 찾고, 과목·단원의 풀이 현황을 확인한다. 근거는 **현재 등록된 출제 가능한 문항 기준**이다. 전체 시험 범위의 완성도·합격 가능성·객관적 난이도나 오답 원인을 추정하지 않는다.

## 화면 사용

기존 실행 방법으로 서버를 연 뒤 `http://127.0.0.1:5173/?view=original&mode=real`에 접속한다. 홈의 **복습 단원 추천**은 전체 연도·회차의 현재 저장 영역을 보여준다. **학습 현황 보기** 또는 메뉴의 **학습 현황**으로 별도 화면을 연다. 기능 시연은 저장 영역을 demo로 전환해 확인한다.

학습 현황의 **현황 과목·현황 시험 연도·현황 회차**는 집계할 자료 범위를 바꾼다. 응답일로 기간을 자르지 않는다. 기본값은 세 과목·전체 시험 연도·전체 회차다. 적용 중인 범위가 화면에 표시되며 같은 범위의 요약·추천·단원 현황을 함께 갱신한다.

**단원 표시**는 전체 / 미풀이 있음 / 복습 필요이며, **단원 정렬**은 기본 단원 순 / 풀이율 낮은 순 / 오답률 높은 순이다. 이 두 조작은 단원 행의 표시만 바꾸며 과목 요약과 추천의 모집단을 바꾸지 않는다. 비율이 없는 단원은 비율 정렬의 끝에 두고 동률은 등록 순서를 따른다.

과목 카드에서 풀이 문항·미풀이·미해결·모르겠음·분류 대기와 상태를 확인한다. 단원 행에는 풀이율·오답률·표본 부족·미해결·반복 오답·최근 유효 응답일을 표시한다. 형사소송법의 수사·증거는 기존 레지스트리의 **임시 대분류**로 표시한다.

추천의 **이 단원 복습** 또는 단원 행의 **복습**은 현재 범위의 해당 주 단원에 속한 오답·모르겠음만 시작한다. **미풀이 풀기**는 현재 채점 버전에서 유효 응답이 없는 문항을 시작한다. 각각 최대 20문항이며 자료가 적으면 실제 수만 시작한다. 분류 대기는 과목별 별도 영역에서 수치를 확인하고 학습할 수 있다.

## 모집단과 단원 귀속

헌법·형사법·경찰학의 현재 namespace와 조회 범위에서 기존 `isEligible` 기준을 만족하는 고유 questionId만 센다. 실제 영역은 현재 허용된 순경 원문·공식 최종 정답·검수 완료·활성 조건을 따른다. 시연 영역은 기존 demo 적격성 조건을 따른다. 삭제 표시·퇴역·원문/정답 보류·미확정 등 기존 출제 제외 문제는 통계·추천·새 복습에서 제외한다. 범죄학·민법총칙은 활성화하지 않는다.

주 단원이 confirmed이고 같은 과목의 유효한 studyUnitCode일 때 그 단원 한 곳에 귀속한다. relatedStudyUnitCodes나 기본서 연결로 다른 단원에 중복 집계하지 않는다. 분류 null/pending 또는 유효한 주 단원이 없는 문항은 **분류 대기**로 센다. 분류 대기도 과목 전체에는 포함한다.

따라서 과목 합계는 주 단원 합계와 분류 대기의 합이다. 비율을 합칠 때는 고유 문항 수의 합으로 계산하며 단원 비율의 평균을 사용하지 않는다. 분류만 수정하면 현재 주 단원으로 이동시키고 과목 전체의 응답 문항 수는 유지한다.

## 고유 문항의 최근 유효 응답

현재 questionId와 gradingRevision이 같은 확정 Attempt 중, 번호 1~4의 correct/incorrect 또는 unknown 응답의 unknown 결과만 유효하다. 같은 문제를 여러 번 풀어도 대표 상태는 하나다. 저장된 attempts 배열을 뒤에서 읽어 가장 나중에 확정 저장된 유효 응답을 사용하며 answeredAt으로 배열을 재정렬하지 않는다. 시각이 같은 응답도 뒤에 저장된 기록이 최근이다.

- 모의고사 공란(response=null 또는 unanswered)은 유효 응답에서 제외한다. 정답·오답·모르겠음 뒤에 공란이 저장되어도 앞의 유효 상태를 유지한다. 공란만 있는 문항은 미풀이로 남는다.
- 제출 전 실전 임시 선택은 포함하지 않는다. 진행 중 일반 학습의 이미 확정 저장된 응답은 포함한다.
- 오답 뒤 정답은 현재 오답·복습에서 빠진다. 과거 이력은 보존한다.
- gradingRevision이 바뀌면 이전 채점 버전의 응답은 현재 지표에 사용하지 않는다. 분류만 바뀌어 revision만 증가하면 응답을 계속 사용한다.
- 수동 다시 보기 표시만으로 풀이·오답 상태를 만들지 않는다. 기존 모의고사의 공란 0점 규칙과 기존 OX/원문 복습 기록 규칙은 유지한다.

최근 응답일 표시는 현재 채점 버전의 모든 유효 응답 중 가장 큰 answeredAt 시각이다. 이는 대표 응답을 정하는 확정 저장 순서와 구분한다. 단원의 최근 응답일도 그 단원의 해당 시각 중 가장 최근 값이다.

## 지표 공식

| 기호 | 의미 |
|---|---|
| N | 현재 범위의 출제 가능한 고유 문항 수 |
| A | 현재 채점 버전에서 유효 응답이 있는 고유 문항 수 |
| C | 최근 유효 응답이 정답인 문항 수 |
| W | 최근 유효 응답이 오답인 문항 수 |
| U | 최근 유효 응답이 모르겠음인 문항 수 |
| B | 정오 판정 문항 수: C + W |
| M | 미풀이 문항 수: N − A |

항상 `A = C + W + U`, `N = C + W + U + M`이다.

| 지표 | 공식 | 분모가 0일 때 |
|---|---|---|
| 풀이율 | A / N | 값 없음 |
| 오답률 | W / B | 값 없음 |
| 미해결 문항 | W + U | 0문항 가능 |
| 미해결률 | (W + U) / A | 값 없음 |

모르겠음은 풀이율에 포함하고 오답률의 분자·분모에서는 제외한다. 모르겠음만 있는 단원은 오답률 100%가 아니다. 내부 비율 원값으로 비교하고 화면에서만 소수점 한 자리로 반올림한다. 값 없음은 **—**로 표시하며 0.0%와 구분한다.

반복 오답 문항은 현재 미해결인 문항 중 현재 채점 버전의 최근 유효 응답 최대 3개 안에 incorrect가 2회 이상 있는 고유 문항 수다. unknown도 이 3개 범위에 포함되지만 incorrect로 세지 않는다. 최근 유효 응답이 correct인 문제는 반복 오답 후보에서 제외한다. 반복 횟수를 W에 더하지 않는다.

## 추천 순서와 표본 기준

중앙 상수는 `MIN_GRADED_QUESTIONS=5`, `MAX_RECOMMENDATIONS=3`, `DEFAULT_REVIEW_LIMIT=20`이다. 5문항은 작은 표본이 우선순위를 과도하게 바꾸는 것을 줄이기 위한 제품 기본값이다. 통계적으로 입증된 신뢰도 경계로 표현하지 않는다.

우선 추천군은 `W>0`이고 `B>=5`인 단원이다. 오답률 W/B 내림차순 → W 내림차순 → 반복 오답 문항 수 내림차순 → 단원의 최근 유효 응답일이 오래된 순 → 과목·단원 레지스트리 순으로 정렬한다.

우선 추천군으로 3개를 채우지 못하면 나머지 미해결 단원을 보충한다. 보충 추천군은 미해결률 내림차순 → 미해결 문항 수 내림차순 → 반복 오답 수 내림차순 → 최근 유효 응답일이 오래된 순 → 레지스트리 순이다. 우선 추천군이 항상 보충 추천군보다 앞선다.

`B<5`는 **표본 부족·추가 확인**, `B>=5, W=0, U>0`는 **모르겠음 복습**으로 안내한다. 예를 들어 10문항 중 오답 4개인 우선 추천 단원이 1문항만 틀린 100% 단원보다 앞설 수 있다. 추천 근거 문장은 오답 분자/분모와 모르겠음 수에서 직접 만들며 외부 모델에 요청하지 않는다.

홈과 학습 현황은 같은 범위에서 같은 집계·추천 순서를 사용한다. 카드에는 순서·과목·단원, 오답률과 W/B, 모르겠음, 풀이율과 A/N, 미해결·반복 오답 수, 근거 문장 및 이번 복습 문항 수를 표시한다. 단원 미확정 미해결은 별도 개수로 알리고 임의 단원에 배정하지 않는다.

미해결이 없으면 **현재 복습할 오답·모르겠음 문항이 없습니다.**라고 표시한다. 정답 문항으로 추천 수를 채우지 않는다. 미풀이가 있으면 별도 미풀이 학습으로 안내한다.

## 실제 시작 목록과 현재 상태 확인

복습 목록은 같은 범위·주 단원에서 최근 유효 응답이 incorrect/unknown인 ID 집합이다. 오답 → 모르겠음 순이며 각 상태 안에서 반복 오답 우선 → 해당 문항의 최근 유효 응답이 오래된 순 → 안정적인 ID 순이다. 정렬 후 min(20, 미해결 수)만 넘긴다. 관련 단원이나 정답을 끼워 넣지 않고 원문 선택지 순서도 유지한다.

클릭 시 저장소를 다시 읽고 원자적 저장 작업 안에서 현재 상태로 집계·선별한다. 다른 탭의 답 제출, 가져오기, 삭제, 채점 버전 변경 후 카드가 오래되어도 이전 ID 목록을 그대로 시작하지 않는다. 후보가 없어졌으면 최신 현황과 안내를 보여준다. 미풀이 역시 공란을 제외한 유효 응답 없음 기준으로 현재 상태에서 최대 20문항을 선택한다.

진행 중 세션이 있으면 그 세션을 이어가고 새 세션으로 교체하지 않는다. 종료 시각이 지난 시험은 기존 규칙으로 확정한다. 현황을 보는 동안에도 deadlineAt 기준 시험 시간은 흐르며, 추천 클릭으로 제한 시간을 다시 시작하지 않는다. 복습에서 정답을 확정 저장하면 그 문항은 즉시 미해결·추천 집계에서 빠진다.

## 상태 문구와 시각화

| 조건 | 표시 |
|---|---|
| N=0 | 등록 문항 없음 / 과목 카드의 문제 등록 필요 |
| N>0, A=0 | 미학습 과목 / 미풀이 단원 |
| N>0, A>0, M>0 | 학습 진행 중 |
| N>0, M=0 | 전체 문항 응답 완료 |

전체 문항 응답 완료를 완전 숙달로 해석하지 않는다. 오답·모르겠음이 남아 있을 수 있다. B<5이면 오답률 옆에 표본 부족을 표시하고 W+U>0이면 복습 수를 알린다.

가로 누적 막대는 N을 분모로 정답 C=초록, 오답 W=빨강, 모르겠음 U=주황, 미풀이 M=회색을 사용한다. N>0일 때 합은 100%이며 풀이율은 A/N이다. 범례와 수치를 함께 제공하므로 색만으로 상태를 구분하지 않는다. progressbar의 aria 값과 텍스트도 A/N을 따른다. N=0은 등록 문항 없음으로 표시하고 시작할 문항이 없으면 버튼을 비활성화한다. 기존 글자 크기와 키보드 포커스를 사용한다.

## 검증 기록

기존 단위/통합·브라우저 검증과 새 집계 검증을 사용한다. 브라우저는 격리된 컨텍스트의 기존 도형·색상 시연 문항과 검증된 전체 백업을 사용한다. 사용자 프로필의 기록에 시험 응답을 만들거나 기록을 삭제하지 않는다.

새 브라우저 검증 범위는 홈/현황 추천 순서 일치, 공란 뒤의 유효 응답 유지, 주 단원만 집계·복습, 조회 범위와 행 필터 분리, 복습 정답 후 즉시 갱신, 공란만 있는 문항의 미풀이 시작, 최대 20문항, 다른 탭 갱신 후 오래된 카드 클릭, 진행 중 시험과 실제 종료 시각 보호, 실제/시연 분리, 분류만 바뀐 가져오기·삭제·전체 복구 후 재집계다.

이 실행 환경에서는 `Get-Command`로 npm 실행 파일이 없음을 확인했다. 기존 package.json의 도구 진입점을 설치된 Node로 직접 실행하며 의존성을 교체하지 않는다.

```text
node node_modules/vitest/vitest.mjs run
node node_modules/typescript/bin/tsc -b
node node_modules/vite/bin/vite.js build
node scripts/run-e2e.cjs --reporter=line
```

여기서 node는 `C:/Users/INTEL/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe`다. npm이 있는 일반 환경의 명령은 `npm test`, `npm run build`, `npm run test:e2e`다. 기존 Node 24/Playwright 1.52 호환 실행기는 같은 테스트 소스를 임시 CJS로 변환해 실제 Chromium에서 실행한다.

최종 검증 결과:

- 단위·통합 테스트: **10개 파일, 148/148 통과**. 새 집계 경계 사례 47개 포함.
- 빌드: **TypeScript 검사와 Vite 프로덕션 빌드 통과**.
- 전체 브라우저 테스트: **19/19 통과**. 기존 15개와 새 복습·현황 흐름 4개 포함.

`test-results/review-recommendations-1440.png`와 `review-unit-1280.png`를 시각 확인했다. 세 추천 카드의 근거·분자/분모·표본 부족·누적 막대·복습 수와 단원 행의 세부 수치가 읽히며, 모르겠음만 있는 단원의 오답률은 —로 표시한다. 1280×720, 1440×900, 565×672에서 기본 글자와 200% 글자를 각각 확인했고 가로 넘침이나 페이지 실행 오류가 없었다.

조회 범위는 현재 등록된 출제 가능 문항의 과목·시험 연도·회차다. 응답일 기간 조회나 전체 시험 범위의 학습 완성도 추정은 제공하지 않는다.
