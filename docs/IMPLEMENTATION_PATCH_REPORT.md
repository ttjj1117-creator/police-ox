# 통합 구현 패치 보고서

작성: 2026-10-26, Asia/Seoul. 기준 공개 버전: PR4/main `8b942e7a74fecdfe47b19a9c44623e620a7ae6fd`.

## 반영 상태

구현·검증을 마치고 **로컬 기준 앱에 소스와 지원 파일 33개를 반영했다.** 공개 배포 금지에 따라 main 병합·웹 배포·실제 해설 업로드는 수행하지 않았다. 초기 미검증 일괄 반영과 타입 검사만 한 핵심 반영은 자동 승인 검토가 거부했다. 먼저 부분 변경을 PR4 원본으로 복구하고, 별도 검토본에서 실제 기능·전체 회귀를 마친 뒤 파일별 SHA·복구 사본·실패 시 복구 절차를 갖춰 최종 반영 승인을 받았다. 실제 기준 앱에서도 407개 단위 검사와 앱/도구 타입·빌드를 통과했다.

## 사용자 동작과 실제 수정

- **연속 종이 면**: 기존 body/choice-N의 독립 SVG 표면과 클리핑이 블록 경계에서 획을 나누던 원인이었다. 새 획은 본문·보기·선택지·사이 여백을 포함하는 paper 표면의 동일 CSS 좌표계에 저장한다. 펜 시작점의 버튼·링크는 필기 시작에서 제외하고, 종이에서 시작한 캡처 획은 번호 위로 지나가도 답을 선택하지 않는다. SVG는 스크롤 콘텐츠에 붙는다. 마우스로 텍스트를 선택할 수 있는 DOM은 유지한다.
- **기존 필기 보존**: 문서 스키마/owner/ns/session/question/contentVersion 및 InkStore의 쓰기 큐·실패 복구를 유지한다. 기존 좌표를 새 종이 좌표로 오해석하거나 삭제하지 않는다. 기존 body/choice 획이 있으면 이전 필기 배치 보기를 제공한다. 같은 폭·글씨·줄바꿈의 이전 표면에서 읽기 전용으로 복원하며, 다른 배치는 계속 보관 안내한다. 이전 버전에서 직접 생성한 중립 저장 문서의 path를 새 앱에서 정확히 비교했다. 필기는 여전히 이 기기 전용이며 전체 백업/기기 동기화 제외다.
- **세션 범위 입력 정책**: 문항별 InkProvider 바깥의 QuizInputGuard가 read/pen/eraser를 관리한다. 첫 진입·다른 계정/세션·화면 이탈·blur는 이동·읽기, 같은 세션의 문항 이동은 선택한 상태를 유지한다. 펜 전용에서는 펜이 닿기 전과 뗀 뒤에도 학습 면·번호·도구·메뉴·답안표·종료 확인의 손 입력을 차단한다. touch-action은 접촉 전에 준비하고 후속 pointer/click/호환 이벤트를 함께 처리한다. 기존 수동 InkFingerPan 우회 경로는 사용하지 않는다.
- **잠금 해제**: 펜/마우스/키보드로 이동·읽기를 선택하거나, 왼쪽 전용 해제를 한 손가락으로 1.2초 길게 누른다. 이동·취소·이탈·다중 접촉은 취소한다. 진행 상태를 표시하고 해당 접촉의 후속 클릭을 막는다. 잠금 해제는 종료 확인창 위에서도 접근할 수 있다. PointerEvent 미지원 환경은 제한 안내와 TouchEvent 복구 경로를 제공한다.
- **좌측 종료·앱 내 확인**: 상단 왼쪽에 일반 학습 종료/시험 제출을 배치한다. 일반 학습과 모의고사의 의미는 구분하고 취소가 기본 포커스다. window.confirm을 앱 대화상자로 교체했다. 확인 전에는 finish/이동을 실행하지 않으며 획 마무리·저장 확인 후 기존 답안 저장 경로를 한 번만 실행한다. 실패 시 창을 유지하고 재시도/취소를 제공한다. 타이머는 멈추지 않으며 만료 제출이 수동 확인창보다 우선한다.
- **가독성**: 22 CSS px 기본 글씨, 저장 배율 한 번 적용, 카드 전체 폭, 번호 48px, 접힌 오버레이 답안표, 원문 문자열을 보존하는 자동/원문 줄바꿈을 유지한다. 새 도구가 보통 분량의 화면을 불필요하게 밀지 않도록 이전 필기 버튼은 보관 획이 있을 때만 표시한다.
- **해설 자료와 열람**: 별도 Zod 규약, 구조 선택자·정확한 원문·SHA-256·채점 버전 검증, 근거/쟁점/지문 해설 다대다 참조를 구현했다. PackageManager 옆에서 검증 미리보기·원자 교체·파일 내보내기를 지원한다. 일반/회차별은 답 제출 후, 모의고사는 종료 후에만 해설·발췌를 보여준다. 자료가 없거나 초안/보류/오래된 버전인 경우를 구분한다. 패널은 필기 면 밖에 있다. 외부 원문은 새 창으로 연다. 실행 중 GPT/검색/법률 생성은 없다.
- **출제 빈도**: 현재 eligible·삭제 제외 원본과 일치하는 verified 연결만 사용한다. 문제/회차/지문을 별도 집합으로 집계하고 여러 쟁점의 근거 합계는 합집합이다. 중복 원본 출처는 보고하고 충돌은 제외한다. 시험·과목·연도·회차 필터, 연결 문항 비율/미연결/검토/버전 불일치, 쟁점별 목록, 관련 기출 풀이 이동을 제공한다. 진행 중 모의고사에서는 분석을 숨기고 기존 세션을 훼손하지 않는다. 새 복습 점수나 미래 확률은 만들지 않았다.

## 실제 자료와 시연 범위

실제 판례·법률 해설 파일은 이번 작업에서 제작·등록하지 않았다. 중립 도형·색깔 100문항, 근거 2개·쟁점 3개·해설 6개(draft/hold 포함)로 입력/참조/집계를 검증한다. 시연의 verified는 테스트 확인 상태이며 법률 검증이 아니다. 실제 1,000문항 전체의 법률 해설 완료를 뜻하지 않는다.

별도 데이터 생성 채팅에는 규약 문서, 실행 검증기, 대상 후보 내보내기 명령, valid/invalid/stale 예시를 전달한다. 실제 자료가 같은 규약을 따르면 앱 코드를 다시 수정하지 않고 가져올 수 있다.

## 실기기와 구체적 제약

CSS viewport 800×1280, 960×1536, 1280×800, 1536×960, 640×900, 1440×900, 360×800 및 배율 100/125/150/200%를 자동화 범위에서 검사한다. 이 수치가 실제 Tab S11의 고정 viewport라고 주장하지 않는다.

Chromium의 합성 PointerEvent와 CDP 펜/터치 입력은 앱의 라우팅·저장·기본 브라우저 경로를 확인한다. 실제 Tab S11 S Pen의 필압 느낌·지연·손바닥 접촉·회전, Samsung Internet은 이 환경에서 확인하지 못했다. 웹앱의 입력 잠금은 브라우저 바·운영체제 제스처·하드웨어 터치를 끄는 기능이 아니다. 이전 필기는 같은 배치에서만 표시하며 임의로 늘려 다른 문장에 덮지 않는다.

## 적용과 배포

로컬 기준 앱 반영까지 완료했다. 초기 자동 승인 거절은 기능 검사와 파일별 검증·복구 절차를 갖춘 더 안전한 최종 반영으로 해결했으며 우회 실행하지 않았다. **이 문서 작업만으로 main 병합·GitHub Pages 배포는 하지 않는다.** 공개 앱 업데이트는 별도의 검토·승인 단계로 남긴다.
