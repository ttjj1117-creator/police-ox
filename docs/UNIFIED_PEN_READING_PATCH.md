# S펜 자동 필기와 가로 글줄 수정

2026-10-26 정정: 현재 사용법과 검사·배포 결과는 [자동 입력 정정 기록](AUTO_PEN_TOUCH_CORRECTION.md)을 따른다. 중간 통합 패치에 들어갔던 모드 전체 손 잠금·이동/읽기 전환·1.2초 해제는 현재 일반 풀이의 사용법이 아니다.

읽기/연필 전환을 없애고 문항 위에서 펜은 필기, 한 손가락은 이동에 사용한다. 가로 화면에서 짧은 PDF 개행 때문에 글줄이 왼쪽에 머물던 문제를 가역적인 읽기 표시로 수정한다.

## 동작

- 기본 도구는 연필이다. 연필/지우개는 펜 입력에만 적용한다. 손가락과 마우스는 필기를 생성하지 않는다.
- 한 손가락을 일정 거리 이상 움직이면 문항이나 넓은 그림의 스크롤 영역을 이동한다. 번호를 짧게 누르는 동작은 답을 선택하고, 드래그·다중 접촉·펜 접촉 중 손 접촉은 답을 선택하지 않는다.
- 문항 표면의 제스처 정책은 접촉 전에 준비한다. 한 손가락 이동은 앱에서 스크롤 가능한 조상으로 전달한다. 현재 touch-action 값과 확대 지원 범위는 [자동 입력 정정 기록](AUTO_PEN_TOUCH_CORRECTION.md)을 따른다. 브라우저의 기본 관성 스크롤과 같은 동작을 보장하지 않는다.
- 실제 펜 입력 중 관찰되는 손 접촉은 이동·답 선택에서 제외한다. 손이 먼저 이동하던 경우 펜이 닿으면 그 이동을 중단하고, 무효화한 손 접촉은 up/cancel까지 계속 제외한다. 펜을 뗀 뒤 새 유효 손가락 조작은 자동으로 다시 사용한다. 도구 선택이나 단순 호버·최근 펜 사용 이력만으로 계속 손을 막지 않는다. 하드웨어나 브라우저가 전달하지 않은 접촉까지 판별하는 기능은 아니다.
- `줄바꿈 자동`은 짧은 단일 개행을 화면 폭에 맞춰 이어 표시한다. 빈 문단·명시적 보기 항목·독립 안내·표 형태의 행은 경계를 유지한다. `줄바꿈 원문`은 원래 개행 표시로 돌아간다. 설정은 기기·자료 영역·계정별 로컬 선호값이다.

## 보존

문제 문자열·문항 ID·채점·세션·응답·글씨 배율·클라우드 프로토콜은 변경하지 않는다. 원문 문자열은 자동 표시에서도 그대로 유지한다. 보기의 의미를 판단하거나 원문을 다시 저장하지 않는다.

필기의 저장소·문서 형식·자료 소유자·세션·문항 식별자·내용 버전은 유지한다. 기존 배치의 필기는 별도로 보관하며 원래 화면 크기·글씨 크기·원문 표시로 돌아오면 해당 배치에서 다시 표시한다. 필기는 계속 이 기기에만 저장되고 일반 백업·기기 동기화에는 포함되지 않는다.

## 이전 자동 입력·가로 글줄 패치의 검증 기록

아래 수치는 PR4 단계의 과거 결과다. 현재 정정 패치의 결과는 [별도 기록](AUTO_PEN_TOUCH_CORRECTION.md)에서 확인한다.

단위 검사 28개 파일·389개, 앱·변환 도구 TypeScript 검사, `/police-ox/` 배포 빌드(97개 모듈)가 통과했다. 브라우저 검사 52개를 확인했다. 전체 실행 중 소스 HMR과 오프라인 재연결이 겹친 동기화 검사 1개는 소스 변경 없이 독립 재실행해 통과했다. 새 입력·글줄·배치별 획 복원 검사도 통과했다.

1280×800 중립 시연 자료에서 실제 글자 Range로 최대 글줄 사용률을 측정했다. 짧은 원문 개행 표시에서는 약 41.0%, 자동 표시에서는 약 99.9%였다. 자동 표시의 저장 원문과 DOM 문자열은 모두 동일했다. 문장 사이의 실제 글자 간격, 별도 문단·목록, 125~200% 글씨, 좁은 화면과 회전도 검사했다. 카드 외곽 폭만으로 해결 여부를 판단하지 않았다. 사용자 화면이나 개인 문제·학습 기록은 공개 증거에 포함하지 않는다.

Chromium 자동화는 입력 처리·저장 보존을 확인한다. Galaxy Tab S11 실물 S펜의 지연·압력 느낌·운영체제 손바닥 거부 동작은 별도 기기 확인이 필요하다.

## 입력 정책 근거

펜과 터치의 기본 이동은 접촉 시작 시점의 `touch-action` 및 조상 요소 정책에 영향을 받는다. 접촉 후 스타일을 바꾸는 방식에 의존하지 않는다. [W3C Pointer Events](https://www.w3.org/TR/pointerevents3/#determining-supported-direct-manipulation-behavior), [MDN touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action).
