# PC 기록을 같은 웹 주소의 갤탭으로 옮기기

2026-10-23. 문제은행과 **완료·종료한 원문 풀이 기록**을 같은 계정으로 공유한다. 진행 중인 답안과 모의고사 타이머는 시작한 기기에 남는다. 글자 크기도 기기별로 저장한다. 기존 OX와 시연 영역은 원문 real 클라우드 동기화에 합치지 않는다.

## 1. 기존 PC에서 백업 보관

1. 기존 PC 앱 `http://127.0.0.1:5173/?view=original&mode=real`을 연다. `저장 영역`이 실제 학습인지 확인한다.
2. 가능하면 진행 중 학습을 `학습 종료`, 모의고사를 `시험 제출`로 마친다. 종료는 남은 일반 학습 문항을 임의 오답으로 바꾸지 않는다.
3. `데이터·설정`의 `전체 백업 내보내기`로 JSON 파일을 저장한다. 이 파일은 원문과 기존 OX를 함께 보존할 수 있는 개인 백업이다. 원본 파일을 따로 보관하고 공개 GitHub 저장소에 올리지 않는다.

이전 PC 기록을 삭제할 필요는 없다. 파일 복사나 새 웹 주소 접속만으로 예전 브라우저 기록이 자동 이전되지는 않는다. localhost와 HTTPS 주소는 서로 다른 origin이며 각자 저장소를 쓴다.

## 2. PC의 웹 앱에서 계정 연결

1. 기존 GitHub Pages 주소를 PC 브라우저에서 연다. 정식 주소는 배포 결과에서 확인하며 기본 후보는 `https://ttjj1117-creator.github.io/police-ox/`다.
2. `계정·기기 동기화`에서 같은 개인 이메일로 `로그인 메일 받기`를 누른다. 현재 기본 설정은 메일의 로그인 링크를 누르는 방식이다. 앱을 사용할 브라우저에서 링크를 열고 연결된 이메일을 확인한다. 번호가 포함된 메일을 받는 프로젝트에서는 기존 번호 입력도 사용할 수 있다. 기본 메일은 Supabase 조직에 등록된 본인 이메일만 받을 수 있고 발송 제한이 있으므로 여러 번 연달아 요청하지 않는다. `설정 필요`가 보이면 [웹 배포 안내](WEB_DEPLOYMENT.md)를 확인한다. 이번 연결의 공개 값은 GitHub 배포 설정에 등록했다.
3. `기존 PC 기록 연결`의 `기존 PC 실제 학습 백업`에서 1단계 파일을 선택한다. 현재 웹 주소의 로그인 전 로컬 기록을 연결할 때는 `로그인 전 이 기기 기록 미리보기`를 사용할 수 있다.
4. 미리보기의 문제 수·완료/종료 세션 수·공유할 응답 수·내용 충돌 수를 확인하고 `미리보기 확인하고 계정에 연결`을 누른다. 다른 사람의 기록을 자동 연결하지 않으므로 계정 이메일과 파일 소유자를 확인한다.
5. `지금 동기화`를 누르고 `동기화 완료`와 마지막 성공 시각, 전송 대기 수를 확인한다. `이 기기에 저장됨`이나 `오프라인·전송 대기`만으로 전송 완료를 판단하지 않는다.

기존 클라우드에 기록이 있으면 ID를 유지해 합친다. 같은 백업을 다시 연결해도 같은 내용의 세션·응답을 새로 만들지 않는다. 같은 ID의 내용이 다르면 자동 덮어쓰지 않고 충돌로 보관한다. 빈 파일이나 로컬 전체 복구를 클라우드 전체 초기화 명령으로 쓰지 않는다.

백업에 진행 중 세션이 있으면 완료된 기록만 공유하며 그 진행 세션은 다른 기기의 활성 세션으로 옮기지 않는다. 기존 PC에서 마친 뒤 새 백업을 만들고 다시 연결하는 것이 안전하다. 원본 백업의 OX 자료는 별도로 보존하며 필요하면 `연결한 원본 전체 백업 내보내기`로 다시 저장할 수 있다. 웹의 기존 OX 학습실에 복구할 때는 OX/원문 백업 검증·미리보기 절차를 이용한다.

## 3. 갤탭에서 내려받기

1. 갤탭 Chrome에서 **같은 웹 주소**를 열고 PC와 **같은 이메일 계정**으로 로그인한다. 설정을 앱 화면에서 직접 넣었다면 갤탭에서도 같은 공개 연결값을 등록한다. GitHub 빌드 설정에 등록했다면 화면에 기본 제공된다.
2. `지금 동기화`를 누르고 완료 시각과 이 기기의 문제·그림 수를 확인한다. 처음에는 연결된 상태로 다운로드를 마친 뒤 오프라인으로 사용한다.
3. PC에서 종료한 세션과 응답, 다시 보기, 학습 현황·복습 추천을 확인한다. 아직 PC에서 풀고 있는 세션의 임시 답안이 갤탭에 없다는 것은 이번 동기화 범위에 맞는 동작이다.
4. 원하면 Chrome 메뉴에서 앱을 설치한다. 설치하지 않고 브라우저에서 계속 써도 된다. Samsung Internet의 메뉴 이름과 설치 동작은 실제 기기에서 확인한다.

## 학습·오프라인·복구

다운로드를 마친 문제와 그림은 연결이 끊겨도 이 기기에서 풀 수 있다. 답안은 먼저 이 기기에 저장한다. 일반 학습은 왼쪽 `학습 종료`, 모의고사는 `시험 제출`의 앱 확인창에서 종료한다. 완료/종료 기록은 기존 전송 대기열에 보관하고, 앱을 다시 열거나 네트워크가 돌아오면 재시도한다. 별도 종료·동기화 버튼이나 전송 완료를 기다리는 단계는 없다. 브라우저를 종료한 상태의 백그라운드 전송을 보장하지 않는다. 계정 화면의 기존 `지금 동기화`는 필요한 경우 그대로 사용할 수 있다.

두 기기에서 서로 다른 학습을 마치면 양쪽 기록을 보존한다. 오래된 기록 도착만으로 더 나중의 정답을 지우지 않는다. 응답의 선후 관계를 확정하기 어려우면 `응답 순서 확인 필요`로 따로 표시하고 두 원본 중 실제 대표 기록을 선택하게 한다. 문제/기록의 내용 충돌이나 저장 오류가 보이면 먼저 전체 백업과 `동기화 대기열·충돌 복구 파일`을 보관하고 안내에 따라 재시도한다.

로그아웃하면 개인 화면을 닫고 미전송 기록을 같은 계정의 이 기기에 보관한다. 다시 같은 계정으로 로그인하면 전송한다. 다른 계정이나 시연 영역에 옮겨 보내지 않는다. 진행 중 학습은 먼저 종료해야 계정을 바꿀 수 있다.

새 앱 버전 알림은 진행 중 풀이를 자동 새로고침하지 않는다. 학습을 마친 뒤 `앱 업데이트 적용`을 누른다. 브라우저 데이터 삭제·앱 삭제는 답안 보존 방법이 아니므로, 주기적으로 개인 전체 백업을 따로 저장한다.

현재 확인 범위는 Chromium의 분리된 테스트 저장소와 CSS viewport 자동화다. 실제 Supabase 연결·메일과 공개 배포 완료 여부는 [웹 배포 안내](WEB_DEPLOYMENT.md)의 검증 범위를 확인한다. 실제 Tab S11 설치 및 Samsung Internet 실기기 확인은 별도로 필요하다.

## OX 자료도 공유하는 경우

OX 문제·학습 기록은 같은 계정을 사용하되 별도 OX 동기화에 연결한다. 통합 백업의 OX 영역이나 기존 OX 백업 v1을 검증·미리보기 후 병합할 수 있다. 원문 데이터·설정에서 통합 백업을 계정에 병합하면 OX 범위도 별도로 표시하며, 진행 중 OX는 먼저 종료하도록 안내한다. [OX PC→갤탭 이전 절차](OX_PC_TO_TABLET_MIGRATION.md)를 따른다.
