# OX 동기화 구현·검증 기록

2026-10-24. 원문 객관식과 같은 로그인으로 OX 문제·완료 기록을 공유하는 추가 변경이다. 기존 OX ID·목차·판단 기준·판단 버전·응답 시각과 백업 v1을 유지한다.

## 로컬 검증

- 전체 Vitest 26파일 **352/352** 통과 후 비로그인 준비 완료 안내의 추가 회귀 1개 통과. 현재 합계 **353개 항목**이다.
- 앱·도구 TypeScript 검사와 91모듈 production build 통과. `VITE_BASE_PATH=/police-ox/`로 빌드한 index의 JS/CSS 경로가 `/police-ox/assets/`임을 확인했다.
- 브라우저 37항목 중 전체 실행 36개 통과. 기존 원문 offline/conflict 한 항목은 같은 코드 단독 재실행도 통과했다. 기존 모의 서버에 새 OX 빈 조회를 지원하고 초기 준비를 기다리는 fixture 보완 뒤 원문 동기화 3개를 재실행해 모두 통과했다. 검증 조건은 그대로 유지했다.
- 신규 OX 독립 브라우저 2개 시나리오는 전체 실행·개별 실행에서 모두 통과했다. 신규 OX 프로토콜19·저장/컨트롤러21, 공통 인증4·계정 백업2·원문 CAS 대기열4·과거 기록 보존 삭제2가 포함된다.

## 기록 보존과 동기화 검사

- 로그인 전 자료 유지, 계정 전환/real/demo 분리, 명시적 연결 미리보기와 반복 백업 중복 방지
- 완료 세션·응답의 원래 식별자/시각/판단 스냅샷 보존, 다른 내용의 같은 ID는 두 원본을 보관
- 전송 응답 유실·앱 재실행·오프라인 종료 후 재연결 시 같은 eventId 재시도, 계정 상태/outbox의 원자 저장 및 실패 rollback
- 기존 활성 학습은 원래 저장 영역에서 유지하고 계정 연결 전 종료. 원격 문제 변경·삭제는 현재 학습 종료 뒤 반영
- 중요 표시 해제, 지문 삭제 이력, 과거 스냅샷·응답 보존. 오래된 백업은 삭제된 지문을 자동 복원하지 않음
- 늦은 과거 응답/기기 시계 오차/순서 충돌의 대표 상태 확인, exam/current 판단 기준 분리
- 두 기기가 동시에 바꾼 문제은행/표시의 선행 CAS 실패 뒤 후속 추측 버전이 우회 전송되지 않도록 차단. 명시적 재검토 후에도 후속 오래된 변경을 자동 승인하지 않음
- 200% 글자 설정, 순회 초기화와 연결된 지문 삭제가 학습 기록을 보존함

위 네트워크 자동화는 모의 Auth·Storage·RPC를 사용한다. 실제 Supabase 및 실기기의 성공으로 확대하지 않는다.

## 실제 서비스 단계

OX 전용 migration과 fail-fast pgTAP54개를 준비했다. 기존 원문 테이블·버킷을 변경하지 않는 분리 구성이다. 실제 SQL/RLS 실행·공개 배포·사용자 자료 연결·실제 갤탭 수신은 승인 후 이어서 확인하며, 이 문서 작성 시점에는 완료로 보고하지 않았다.

원문 배포의 기존 접속 주소와 로그인 설정을 재사용하며 추가 SMTP·유료 요금제·별도 서비스 가입을 요구하지 않는다. 계정이 연결된 OX 백업 복구는 검증된 병합이고 클라우드 전체 교체 명령이 아니다. 기존 로컬 원본 및 이전에 내보낸 개인 백업을 공개 Git에 포함하지 않는다.
