# 자동 펜 필기·손가락 이동 정정

2026-10-26 · Asia/Seoul. 이 문서는 이전 통합 패치의 모드 전체 손 잠금 설명을 대체한다.

**아무 모드 전환 없이 손으로 넘기고 펜으로 쓴다. 실제 펜 접촉 중 손 입력과 그때 무효화한 접촉의 후속 동작만 자동으로 무시한다. 별도 ‘학습 마치고 동기화’ 버튼은 없다.**

## 수정한 입력 정책

`src/original/ink/InputGuard.tsx`의 `mode !== "read"` 상시 잠금, 이동·읽기 도구, 잠금 해제 타이머·버튼을 제거한다. `Ink.tsx`의 기본 도구는 연필이며 지우개는 펜의 필기 도구만 바꾼다. 손가락은 두 도구 모두에서 스크롤과 일반 조작에 사용한다. 도구를 선택한 상태와 실제 pen 접촉 상태를 따로 관리한다.

유효한 펜 접촉을 관찰하면 그동안 들어온 손 접촉과 이미 이동 중이던 손 접촉을 무효화한다. 무효화한 접촉은 펜이 떨어져도 해당 pointerId의 up/cancel까지 이동이나 버튼 클릭으로 승격하지 않는다. 종료된 무효 접촉의 후속 click·호환 이벤트도 막되, 새 유효 손 접촉과 마우스·키보드 입력은 별도로 판단한다. 단순 호버나 최근 펜 사용·도구 선택만으로 새 손 입력을 계속 막지 않는다. blur·숨김·이탈·capture 종료 뒤 접촉 상태를 정리한다.

이전 PR4의 `InkInputCoordinator`·`InkFingerPan`과 스크롤 조상 처리를 참고하여 현재 단일 paper 면에 맞춰 사용한다. 본문·보기·선택지·여백은 같은 필기 표면을 유지하고, 번호·메뉴·답안표·종료 확인창은 조작부로 구분한다. 접촉 전에 정한 제스처 정책과 실제 손가락 스크롤 경로를 함께 사용하며, 이미 시작한 제스처에 뒤늦게 touch-action을 바꾸는 방식에 의존하지 않는다.

`quiz-input-scope`와 하위 요소에는 접촉 전부터 고정된 `touch-action: pinch-zoom`을 적용한다. 한 손가락은 8px 이동 뒤 주축을 고정하는 `InkFingerPan`으로 실제 스크롤 조상에 전달한다. 가로 이동은 넓은 그림·표 등 지역 스크롤 영역에 머물고, 세로는 조상과 페이지로 전달한다. 관성 이동은 구현하지 않는다. 브라우저 네이티브 핀치는 가능한 환경에 위임하되 실제 기기의 확대 품질은 미확인이다.

실제 펜이나 무효화한 네이티브 손 접촉의 TouchEvent는 기본 제스처를 취소한다. 이전 손바닥이 남아 있어도 새 유효 접촉의 start/end는 그것만을 이유로 취소하지 않는다. 새 손가락의 브라우저 클릭이 억제되지 않는지 CDP 실제 터치 탭으로 확인한다. 접촉 ID가 있는 click은 이 세션에서 시작한 유효한 down/up 및 같은 조작부를 요구한다. Pointer Events 미지원 브라우저에서는 필기 미지원 안내와 네이티브 `auto` 손 이동을 사용하며 수동 모드 선택을 요구하지 않는다.

## 종료·동기화 정리

`src/original/OriginalApp.tsx`에서 별도 ‘학습 마치고 동기화’ 버튼, `exitRequest`의 sync 변형, 종료 뒤 강제 `cloud.controller.sync()` 호출을 제거한다. 종료 요청은 단일 boolean이며 기존 왼쪽 `학습 종료`/`시험 제출`이 같은 앱 확인창을 연다. `ink/ExitDialog.tsx`의 sync prop·전용 문구도 제거한다.

종료는 기존 문항/응답과 필기를 이 기기에 저장한 뒤 결과로 이동한다. 전송 완료를 기다리지 않는다. 기존 계정·원문/OX 저장 변경과 전송 큐·재시도·계정 화면 동기화는 유지한다. 타이머 만료 제출, 기본 취소 포커스, 저장 실패 시 재시도도 유지한다.

별도 OX 학습실에도 연결 상태에 따라 같은 문자열로 바뀌던 종료 안내가 있어 `src/ui/App.tsx`의 `syncAfterEnd` prop·조건부 문구를 정리했다. 기존 일반 `이번 세션 종료` 동작을 유지하며 새 종료 버튼이나 확인 흐름을 추가하지 않는다. 기존 OX 완료/종료 후 비동기 전송과 계정 화면 동기화 경로는 유지한다.

## 보존 범위

- 연속 paper 필기, 기존 identity·내용 버전·배치별 저장, undo/redo·지우개·저장 실패 재시도.
- 이전 body/choice 표면은 같은 배치의 읽기 전용 보기로 보존. 이전 좌표를 paper 좌표로 변환하거나 자료를 지우지 않는다.
- 가독성·글씨 배율·원문/자동 줄바꿈·번호만 답 선택·좌측 종료와 앱 확인창.
- 공식 정답·문항 ID·학습 단원·시도/세션·타이머·해설 미등록 상태·해설/빈도 분석 기반.
- 기존 origin, real/demo 및 계정 분리, IndexedDB·백업·클라우드 계약·큐. 필기와 해설은 계속 기기 전용이며 기존 전체 백업·동기화에 자동 포함되지 않는다.

새 모드·실시간 해설 생성·서비스·유료 기능·DB 재설정은 추가하지 않는다. 공개 파일은 앱·문서·중립 검사이며 실제 문제은행·해설 원문·개인 기록·비밀 환경변수는 포함하지 않는다.

기존 `.github/workflows/deploy-pages.yml`, `/police-ox/` base와 공개 Supabase Repository variables를 유지한다. 새 배포는 해당 커밋의 build와 deploy 성공 및 실제 URL의 새 정적 파일·UI를 확인한 뒤 완료로 기록한다. 이전 배포의 성공 run을 이번 결과로 사용하지 않는다.

기존 PWA에서는 진행 중 풀이를 먼저 마치거나 종료한 뒤 `앱 업데이트 적용`을 누른다. 진행 중 풀이를 강제로 새로고침하거나 브라우저 데이터를 지우지 않는다. 다시 열린 문제에서 연필이 기본이고 이동·읽기/잠금 해제 UI 없이 손 스크롤이 작동하는지 확인한다. 연결된 계정의 완료 기록은 원래 전송 정책을 따른다.

## 실기기 확인과 제한

물리적인 Galaxy Tab S11/S Pen 및 Samsung Internet은 이 작업 환경에 연결되지 않았다. 합성 PointerEvent·CDP 터치/펜과 실제 스크롤·선택 결과를 검사하며, 실제 필압 느낌·지연·운영체제 팜 리젝션까지 확인했다고 주장하지 않는다. 앱이 관찰하지 못한 하드웨어 접촉은 판별할 수 없고 브라우저 바·OS 제스처를 제어하지 않는다.

## 공개 파일 및 데이터 보존

현재 소스·검사·안내 문서만 선택적으로 반영한다. 문제·정답·단원·Attempt/Session·InkStore·해설 저장소·백업/클라우드 스키마·Supabase 서버/RLS를 바꾸지 않는다. 실제 문제은행·해설 원문·개인 JSON/필기/기록·.env는 공개하지 않는다. 정정 이전 PR5의 배포 기록은 과거 기록으로 표시하고, 현재 사용법은 이 문서를 따른다.
