# 해설 파일 크기와 계정 동기화

해설 JSON 가져오기의 앱 자체 총 용량 제한을 제거했다. 이전 형식의 20 MiB, 강사 해설의 32 MiB, 해설 이미지별 5 MiB와 이미지 합계 10 MiB 제한을 적용하지 않는다. JSON 구조, 원문 연결, 이미지의 실제 바이트 수·형식·SHA-256 검증은 유지한다. 기기의 메모리와 브라우저 저장 공간, 계정의 서버 저장 용량은 실제 사용 가능 범위에 영향을 준다.

## 사용 방법

1. PC와 갤탭에서 공개 앱의 업데이트를 적용하고 같은 계정으로 로그인한다.
2. PC에 이미 등록한 실제 학습 해설은 다시 가져오지 않아도 자동 전송된다. 동기화 화면에서 해설 상태를 확인할 수 있다.
3. 갤탭에서 앱을 열면 같은 계정의 해설을 내려받는다. 내려받기가 끝난 자료는 인터넷이 없어도 열람한다.
4. 오프라인에서 해설을 가져온 경우 앱을 실행한 상태로 인터넷에 다시 연결하면 전송을 재시도한다. 필요하면 기존 ‘지금 동기화’를 누른다.

브라우저 데이터를 지우거나 기존 문제·학습 기록을 초기화할 필요가 없다. 앱 전체 백업은 기존 원문·OX 데이터 범위를 유지하며, 해설 원본은 ‘강사 해설 내보내기’ 또는 이전 형식 해설 내보내기로 별도 보관한다. 필기 저장·동기화 범위는 변경하지 않는다.

## 저장·충돌 규칙

- 기존 `police-sync-private` 비공개 버킷의 사용자별 `real/explanations` 경로를 사용한다. 기존 로그인과 사용자별 접근 권한을 유지하고 SQL·RLS를 변경하지 않는다.
- 각 전송 조각은 256 KiB 이하이며, 계층형 색인과 최종 원본 해시로 큰 JSON을 검증한다. 최종 목록 파일은 모든 조각 전송이 완료된 뒤 게시한다. 중단된 전송은 다시 시도할 수 있다.
- 서버 파일은 내용 해시로 구분하는 불변 객체다. 빈 기기의 자료를 삭제 명령으로 처리하지 않으며, 같은 패키지의 낮은 버전으로 기존 자료를 교체하지 않는다.
- 같은 패키지·버전에 내용이 다르면 자동으로 하나를 선택하지 않는다. 기존 기기 자료와 서버 원본을 보존하고 오류를 알린다. 올바른 내용의 새 패키지 버전으로 정리한 뒤 다시 가져온다.
- 강사 해설이 등록되면 이전 형식 해설은 활성 화면에서 제외하며 동기화 보관 자료에 유지한다. 오래된 기기에서 다시 보내도 이전 형식이 활성화되지 않는다.
- 로그인 전 `local` 해설은 최초로 연결한 계정에만 복사하고 원본을 보존한다. 로그아웃 상태에서 나중에 가져온 자료도 같은 계정으로 돌아오면 연결한다. 다른 계정에는 자동 복사하지 않는다. 시연 자료는 실제 계정에 전송하지 않는다.
- 다운로드 시 문항 은행을 수정하지 않는다. 해설 표시 시 기존 원문·정답·버전 연결 검사를 다시 사용하므로 일치하지 않는 해설을 강제로 표시하지 않는다.

## 검증

큰 정상·손상 JSON 가져오기, 큰 해설 이미지의 바이트·해시 검사, 두 독립 브라우저의 해설 공유와 오프라인 복구, 빈 기기·계정 전환·버전 충돌·손상 조각에 대한 자료 보존을 중립 시연 자료로 검사한다. 실제 PC 자료의 계정 전송 결과와 공개 배포 버전은 작업 완료 기록에 별도로 남긴다.
