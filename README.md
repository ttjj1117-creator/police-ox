# 경찰시험 OX 학습실

제공된 「경찰시험 OX Codex 구현명세서 1.0」에 맞춘 개인용 웹앱의 기본 코드입니다. React + TypeScript + Vite, IndexedDB로 구성했습니다. 서버·로그인·외부 AI 호출 없이 브라우저 안에 저장합니다.

**실제 기출 지문·정답·해설은 입력하지 않았습니다.** 제공된 기본서 PDF에서 헌법 59개·형법 130개·경찰학 496개 목차 항목을 반영했습니다. 형사소송법은 기존 수사·증거 임시 분류를 유지합니다. 시연 모드는 숫자·도형·색상의 가상 예시 7개를 사용합니다. 모든 시연 화면에 예시 표시가 있고 실제 학습과 저장·통계·백업이 분리됩니다.

목차 원본 대조 목록은 [BOOK_TOC.md](BOOK_TOC.md), 영구 ID를 포함한 데이터는 `src/fixtures/book-taxonomies.json`에 있습니다. 기본서 쪽수와 PDF 목차 페이지를 각각 보관합니다. 실제 모드에 접속하거나 이전 백업을 복구하면 새 목차가 자동으로 추가되며, 문제·응답·세션·사용자 분류는 보존합니다. 기본서의 표기판 연도는 현행 법령 검증을 의미하지 않습니다.

## 실행

Node.js 22 이상을 설치한 환경에서 이 폴더를 터미널로 엽니다.

```sh
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. Node.js는 프로젝트에 포함하지 않습니다. 이미 빌드한 `dist/`도 함께 제공합니다. Python이 있다면 이 폴더에서 다음 명령으로 빌드 결과를 바로 볼 수 있습니다.

```sh
python -m http.server 5173 --bind 127.0.0.1 --directory dist
```

Windows에서는 `실행.cmd`를 더블 클릭해도 Python 서버를 실행할 수 있습니다. 터미널을 닫으면 서버가 종료됩니다. `index.html`을 파일로 직접 열지 마세요. **학습 시 동일한 브라우저·주소·포트를 사용하세요.** 주소가 달라지면 별도의 브라우저 저장 공간을 사용합니다.

```sh
npm test              # 출제·검증·저장·백업 단위/통합 테스트
npm run build        # TypeScript 검사 + 프로덕션 빌드
npx playwright install chromium
npm run test:e2e      # 실제 Chromium에서 UI 흐름 검증
```

## 사용 흐름

1. 처음에는 실제 지문 0개입니다. 홈의 `시연 시작`으로 기능을 확인하거나 `데이터·설정`에서 검증된 문제 JSON을 가져옵니다.
2. 과목, 목차/묶음, 시험 연도·회차, 대상 필터, 출제 모드와 분량을 선택합니다. 판단 기준은 현행으로 고정합니다. 시작 전에 실제 출제 개수를 확인합니다.
   목차는 접힌 계층 목록으로 시작합니다. 단원 이름을 누르면 하위 단원을 펼치고, 왼쪽 체크박스는 해당 단원 전체를 선택합니다. 전체 선택 후 특정 세부 단원만 제외할 수 있으며, 상위 항목에 ‘일부 선택’이 표시됩니다. 접고 펼쳐도 선택 상태는 유지됩니다. 선택을 모두 해제하면 과목 전체를 대상으로 합니다.
3. O/X/모르겠음을 누르면 즉시 제출됩니다. 제출 후에만 정답·정정·이유·근거·출처를 확인할 수 있습니다. 답을 바꿀 수 없으며 근거는 기본 접힘 상태입니다.
4. 새로고침하면 진행 중 세션의 위치와 정답 공개 상태를 복구합니다. 시연/실제 모드 선택은 URL의 `mode`로 유지합니다.
5. 결과에서 이번 세션의 오답·모르겠음·다시 보기 지문을 다시 풀 수 있습니다.

학습·통계는 항상 현행 법령·판례로 검증된 판단을 사용합니다. 현행 미검증 지문을 이전 판단으로 대체하지 않습니다. 이전 기준의 기록은 백업 호환을 위해 보관하지만 화면과 통계에는 표시하지 않으며, 진행 중이던 이전 기준 세션은 종료 처리합니다. 법령·판례를 자동 수집하거나 검증일 이후의 유효성을 자동 보증하지 않습니다. 정답률은 모든 제출(모르겠음 포함)을 분모로 계산합니다. 수동 다시 보기 표시는 나중에 맞혀도 유지됩니다.

## 데이터·백업·복구

- 문제 JSON 내보내기: 분류·묶음·자료 처리 상태·지문만 포함합니다. 형식은 [DATA_FORMAT.md](DATA_FORMAT.md)와 `src/domain/schema.ts`를 참고하세요.
- 가져오기: 20MB 상한과 스키마·타입·중복·참조·순환·검증 필수값·개정 충돌을 검사합니다. 미리보기에서 추가/수정/미변경 건수를 확인한 후 적용합니다. 누락된 기존 지문은 삭제하지 않습니다.
- 전체 백업: 현재 모드의 문제·응답·다시 보기·세션·순회·글자 크기를 JSON 파일로 다운로드합니다. **브라우저 데이터 삭제 전 반드시 백업하세요.**
- 전체 복구: 같은 모드의 전체 백업을 선택하고 미리보기를 확인한 후 교체합니다. 기존 데이터는 합쳐지지 않습니다. 교체 전 현재 전체 백업을 권장합니다.
- 가져오기/복구 전에는 진행 중 세션을 종료해야 합니다. 제출한 응답은 유지됩니다.
- 초기화는 현재 모드의 응답·표시·세션·순회·균형 배정 기록만 지웁니다. 문제·설정은 유지합니다.
- 저장 실패 시 성공으로 표시하지 않습니다. 화면의 `저장 재시도` 또는 `현재 상태 내보내기`를 사용하세요. 내보낸 미저장 상태는 복구 형식으로 보관됩니다.
- 다른 탭의 쓰기와 충돌하면 기존 세대 번호를 검사해 해당 쓰기를 거부하고 최신 저장 상태를 읽습니다. 오류 메시지 확인 후 다시 시도하세요.

## 코드 구조

| 위치                     | 역할                                            |
| ------------------------ | ----------------------------------------------- |
| `src/domain/schema.ts`   | TypeScript 타입, Zod 파일 계약, 교차 참조 검증  |
| `src/domain/engine.ts`   | 필터, 순회/균형/취약 출제, 응답, 통계           |
| `src/data/repository.ts` | IndexedDB 저장, 원자적 갱신, 다중 탭 충돌 방지  |
| `src/data/transfer.ts`   | 문제 병합, 백업 검증, 다운로드                  |
| `src/fixtures/data.ts`   | 빈 실데이터, 임시 분류, 격리된 시연 자료        |
| `src/ui/`                | 홈, 범위 선택, 풀이, 결과, 설정과 모바일 스타일 |
| `tests/`                 | 도메인·저장소 단위/통합 테스트                  |
| `e2e/`                   | 브라우저 흐름 테스트                            |

IndexedDB 스키마 버전 1, 문제 파일 버전 1, 백업 파일 버전 1은 별개입니다. v1 저장소는 실/시연 각각 하나의 aggregate 레코드를 저장하여 응답과 세션 상태를 단일 트랜잭션에서 갱신합니다. 향후 데이터가 크게 늘면 저장소를 정규화하고 마이그레이션을 추가할 수 있습니다.

## 범위와 제한

- 실제 법률의 정확성은 자동 검증하지 않습니다. 프로그램은 검증 표시의 형식과 필수 항목을 검사합니다.
- 기본서 목차·묶음·실제 문제 편집기는 없습니다. JSON으로 등록합니다. 모든 데이터 입력 필드는 일반 텍스트로 표시하며 근거 URL은 HTTP/HTTPS만 허용합니다.
- 로그인, 서버 DB, 기기 간 동기화, PWA 설치·오프라인 캐싱, 공개 배포는 포함하지 않습니다.
- 파일 상한은 문제 가져오기와 백업 복구 모두 20MB입니다. 저장은 브라우저 용량에 영향을 받습니다.
- 브라우저 테스트는 Chromium의 360px 화면과 글자 200% 확대 환경입니다. 안드로이드 실기기·다운로드 앱 연동·iOS는 미검증입니다.
- 동작 검증 기록은 [TEST_RESULTS.md](TEST_RESULTS.md)에 정리했습니다.
